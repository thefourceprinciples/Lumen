# Authority World-Model Crosswalk & 6-Axis Stewardship Audit (`v0.1`)

## 1. Governing Audit Rule
> **A world model may guide attention, but only a constraint-tested world model may guide authority.**

When Lumen evaluates external theories, AI architectures, or institutional frameworks, it scores them across **six structural axes** (`0–3` points each, **Maximum Score = 18**) rather than accepting claims at face value:

| Axis | Audit Question | Score `0` | Score `3` |
| :--- | :--- | :--- | :--- |
| **A. Boundary** | Does the model separate inside/outside, self/world, and jurisdictional limits? | No clear boundary | Rigorous boundary logic |
| **B. Constraint** | Does it explain how continuity survives scarcity, entropy, and error? | No constraint | Rigorous constraint math |
| **C. Feedback** | Does it enforce correction, evidence updating, and repair loops? | No feedback | Strong feedback architecture |
| **D. Local–Global Coherence** | Does it show how local truths scale without contradiction? | No scaling logic | Strong local–global formalism |
| **E. Failure Visibility** | Does it make drift, harm, and collapse structurally auditable? | Failure hidden | Failure structurally auditable |
| **F. Stewardship Fit** | Can it audit legitimacy, custody, burden responsibility, and repair? | Poor stewardship fit | Direct stewardship tool |

## 2. High-Scoring Benchmark Families (`17–18 / 18`)
- **18 / 18:** Network Resilience, Niche Construction, Structural Causal Models, Digital Twins.
- **17 / 18:** Active Inference / Free Energy Principle, Complex Systems Theory, Cybernetics / Control Theory, Systems Thinking / Leverage Points, Panarchy / Adaptive Cycle, Sheaf / Local–Global Reasoning.
