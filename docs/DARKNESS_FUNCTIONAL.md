# The Darkness Functional ($D$) & Persistence Law ($S(t)$)

## 1. Purpose: Early Detection of Silent Failure
**Darkness ($D \ge 0$)** is a dimensionless diagnostic penalty functional (not a physical substance or mystical force) that detects hidden structural degradation before visible system collapse occurs:

$$D = \alpha(1 - r) + \beta N + \gamma F_C + \delta M_I$$

- **Alignment Loss ($1 - r$):** Deviation from global order parameter $r \in [0, 1]$.
- **Noise / Turbulence ($N$):** Variance, unstructured entropy, or unverified signal jitter.
- **Constraint Failure ($F_C$):** Boundary violations or schema/invariant breaches.
- **Interface Mismatch ($M_I$):** Contradictions across overlapping modules or memory stores.

## 2. Exponential Persistence Law
Usable system persistence $S(t)$ decays exponentially as Darkness $D$ accumulates:

$$S(t) = r \, C(\Omega) \, \Phi \, e^{-D}$$

Where $C(\Omega)$ denotes boundary discipline and $\Phi$ represents active energy/token throughput.

## 3. Five Testable Failure Modes
1. **Exponential Attenuation:** Usable persistence drops sharply as $D$ increases.
2. **Interface Dominance:** High mismatch ($M_I$) between subsystems triggers collapse even when individual modules appear healthy.
3. **Historical Hysteresis:** Closed-loop restoration recovers active $S(t)$ without erasing historical distortion records in the ledger.
4. **Local Masking:** High local coherence ($r_{\text{local}} \rightarrow 1$) can mask impending global collapse ($r_{\text{global}} \rightarrow 0$).
5. **High-Throughput Illusion:** Pumping more tokens or compute ($\Phi$) into a misaligned state ($D \gg 0$) accelerates incoherence rather than fixing it.
